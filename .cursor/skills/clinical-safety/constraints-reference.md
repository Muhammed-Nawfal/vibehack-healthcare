# Clinical Safety Constraints Reference

## Complete Flag System

Each answer can raise one or more flags. Flags drive the deterministic rules engine.

| Flag | Complaint | Trigger |
|------|-----------|---------|
| no_movement | RFM | "No movement at all" |
| delayed_presentation | RFM | "Yesterday or longer" since change |
| recurrent_rfm | RFM | Previously contacted maternity team about movements |
| severe_headache | PREECLAMPSIA | Persistent headache |
| visual_disturbance | PREECLAMPSIA | Vision changes |
| sudden_swelling | PREECLAMPSIA | Face/hands/fingers swelling |
| epigastric_pain | PREECLAMPSIA | Pain below ribs, right side |
| feels_very_unwell | PREECLAMPSIA | General unwell feeling |
| heavy_bleeding | BLEEDING | Soaking through a pad / clots |
| severe_pain | BLEEDING | Severe constant pain with bleeding |
| possible_waters | BLEEDING | Clear/straw-coloured fluid leaking |
| discoloured_fluid | BLEEDING | Green/brown fluid leaking |

## Combination Rules

- `heavy_bleeding` AND `severe_pain` → EMERGENCY_999 (overrides any lower disposition)
- Pre-eclampsia: count of positive answers >= 3 → EMERGENCY_999

## Red-Flag Sweep

After the chosen complaint branch, ask one quick question for each OTHER cluster. A positive answer raises disposition to at least MAT_TRIAGE_NOW:

1. "Any bleeding or fluid leaking?" → Yes = MAT_TRIAGE_NOW
2. "Any headache that won't shift, vision changes, or sudden swelling?" → Yes = MAT_TRIAGE_NOW
3. "Have your baby's movements been normal for you today?" → No = MAT_TRIAGE_NOW

## SBAR Template (Clinician-Only)

The SBAR summary is generated by the LLM from session state but must follow this structure:

- **Situation**: Who the woman is, gestation, presenting complaint
- **Background**: Relevant history, what prompted contact
- **Assessment**: Answers given, flags raised, which clusters triggered
- **Recommendation**: Final disposition and recommended action

Plus: timestamp, urgency level, recommended action.

This is NEVER shown to the patient. Only accessible via the separate `/clinician` route.

## LLM System Prompts

```
You are a clinical intake interpreter for a maternity triage tool.
You do NOT diagnose or decide urgency and never speak to the patient.
Map the woman's free-text description to a symptom cluster.
Return ONLY JSON: { "primaryCluster": "RFM|PREECLAMPSIA|BLEEDING|OTHER", "additionalClusters": [...], "extractedSignals": {...}, "urgent999Suspected": true/false }
```

```

Include relevant positives AND the relevant negatives that were screened.

```
